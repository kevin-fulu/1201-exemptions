# §1201 Rulemaking Document Index

Cycle-by-cycle map of the codified `§ 201.40` exemption classes for each triennial Final Rule, paired with the Register's Recommendation. Page numbers refer to PDF/`.txt` page markers (not Federal Register pagination). Topic summaries are short navigation labels — they are NOT a substitute for the regulatory text.

Class labels were generated from the codified text in each Final Rule (verified against the `.txt` extractions). `[NEW]` marks a class appearing for the first time in that cycle. The 2018 Recommendation is the *Acting* Register's Recommendation.

For deep questions: search the corresponding `.txt` file with `grep`, then jump back to the source PDF using `[PAGE N]` markers.

**First-round NPRM comments** (post-petition, pre-opposition) for the 2015, 2018, 2021, and 2024 cycles are archived under `first-round-comments/` — 313 PDFs total, one subdirectory per cycle with a `manifest.csv`. See `first-round-comments/README.md` for layout, filename convention, and the manifest schema. Comments for cycles before 2015 are out of scope (those cycles used a different intake structure).
